##  Features
-  Detects **suspicious keywords** (urgent, verify, lottery, etc.)
-  Flags **malicious URLs** (IP-based, shortened, obfuscated)
-  Provides **risk score + suggestions**
- 🛡️ Helps users avoid phishing attacks
- 🔒 Privacy friendly: **No data stored or transmitted**
